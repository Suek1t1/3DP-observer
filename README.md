# 3D Printer Monitoring & Auto-Shutdown System

このプロジェクトは3Dプリンタの印刷完了を検知し、写真付きでLINE通知を行うとともに、スマートコンセントを用いて遠隔で電源を遮断する監視装置である。

## 1. 制作動機
長時間にわたる3Dプリントにおいて、完了後もプリンタが起動し続けることによる無駄な電力消費を削減したい。また、外出先でも印刷の状態を視覚的に確認し、安心して電源を切れる仕組みを構築することを目的とする。

## 2. 制作内容
3Dプリンタのヘッドが特定の終了座標に到達した際、物理的な接触（電極またはマイクロスイッチ）をトリガーにしてESP32-CAMを起動。現場の写真を撮影してユーザーに通知し、電源をオフにする。

## 3. 制作条件（MVP）
1.  **低消費電力**: 待機時はESP32のDeep Sleepおよび物理スイッチによる完全遮断を活用。
2.  **電池駆動**: 給電なしで運用可能な電源構成。
3.  **完了報告**: 写真付きでLINEに通知。
4.  **電源自動停止**: スマートコンセントと連携した電源遮断。
5.  **物理スイッチ**: 筐体に起動/停止を切り替えるスライドスイッチを搭載。

## 4. 使用機器
### ハードウェア
* **マイコン**: ESP32-CAM
* **センサー**: アルミ箔電極(現段階ではアルミ箔を利用する。誤作動等の問題が顕著であれば、マイクロスイッチ等に変更を考える。)
* **電源**: 電池ボックス（スライドスイッチ付き、自作する。）、単3電池 × 3
* **スマートホーム**: スマートコンセント

### ソフトウェア・技術スタック
* **言語**:
    * C++ (エディタ: Arduino IDE)
    * JavaScript (エディタ: Google Apps Script)
* **プラットフォーム**:
    * Google Apps Script (GAS)
    * LINE Messaging API
* **ストレージ**:
    * Google Drive (写真の一時保存に使用する。)

## 5. システムアーキテクチャ
システムは以下のフローで動作する。

1.  **待機**: ESP32-CAMはDeep Sleep状態。
2.  **検知**: 印刷完了に伴い電極が接地。割込み信号によりESP32-CAMが起床。
3.  **撮影・送信**: 写真を撮影し、GASのWebエンドポイントへPOSTリクエストを送信。
4.  **中継 (GAS)**: 
    * 受信した写真をGoogleドライブに保存。
    * 保存したファイルの公開URLを生成。
    * LINE Messaging APIを介して、ユーザーにテキストと写真URLを送信。
5.  **停止操作**: ユーザーが写真を確認後、Google Homeアプリまたは音声操作でコンセントをオフにする。

# 6. 機能設計

## 機能一覧表

| 機能ID | 機能名 | 優先度 | 概要 |
| :--- | :--- | :--- | :--- |
| F-01 | 印刷完了検知 | 高 | ヘッドの物理的接触を検知し、システムを起動する。 |
| F-02 | 状況写真撮影・データ送信 | 高 | 現場を撮影し、画像データをクラウド(GAS)へ転送する。 |
| F-03 | 画像ストレージ管理 | 中 | 受信した画像を保存し、外部参照可能なURLを発行する。 |
| F-04 | LINE通知（写真付き） | 高 | 完了メッセージと写真URLをユーザーにプッシュ通知する。 |

## 各機能の詳細定義

### F-01：印刷完了検知
*   **機能要件**: Deep Sleep状態から物理的な接触によって即座に復帰し、処理を開始すること。
*   **入力**: 物理接点（GPIOピン）のHIGH/LOW変化。
*   **出力**: マイコンの起動信号。
*   **前提条件**: 電池ボックスのスライドスイッチがONであり、3DプリンタのG-codeによりヘッドが終了位置に移動すること。
*   **事後条件**: F-02プロセスが開始されること。

### F-02：状況写真撮影・データ送信
*   **機能要件**: カメラを起動して造形物を撮影し、Wi-Fiを通じてGASのAPIへデータを送信すること。
*   **入力**: カメラモジュールからのRAW画像データ。
*   **出力**: GAS WebエンドポイントへのHTTP POSTリクエスト（画像バイナリ/Base64）。
*   **前提条件**: Wi-Fi接続が確立されていること。
*   **事後条件**: 送信完了後、ESP32-CAMは再びDeep Sleepへ移行すること。

### F-03：画像ストレージ管理
*   **機能要件**: 送信された画像データをGoogleドライブの指定フォルダに保存し、公開URLを取得すること。
*   **入力**: GASが受信した画像データ。
*   **出力**: Googleドライブ上のファイルIDおよび直リンクURL。
*   **前提条件**: Googleドライブの対象フォルダへの書き込み権限がGASに付与されていること。
*   **事後条件**: F-04へURLが引き渡されること。

### F-04：LINE通知（写真付き）
*   **機能要件**: 印刷が完了した旨のテキストと、F-03で生成された画像URLをセットでユーザーに送信すること。
*   **入力**: 完了メッセージ、画像URL、LINEユーザーID。
*   **出力**: ユーザーのLINEアプリへのプッシュ通知。
*   **前提条件**: LINE Messaging APIのチャネルアクセストークンが有効であること。
*   **事後条件**: ユーザーがスマートフォンの画面上で印刷完了と現地の状況を確認できること。
